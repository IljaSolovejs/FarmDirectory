# CSC1025 2026 – Project 1  
## Group A123  

## Project Title  
Farm & Product Directory  

## Project Description  
This project is a Django-based web application developed as part of the CSC1025 module.  
The website focuses on Food Systems and Agriculture, allowing users to easily explore farms and their associated agricultural products in a structured directory format.  

Users can browse farms, view product details, add new products, and filter products by organic status. The project demonstrates the use of Django models, views, templates, URL routing, and database relationships, while applying agile project management using Trello and version control using GitLab.
